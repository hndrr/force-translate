# ストア掲載情報の下書き

公開前に実機で動作を確認し、管理画面の項目に合わせて入力してください。

## 名前

Force Translate

## 説明

Chrome標準翻訳が効かないページを、Chrome内蔵の翻訳機能で日本語に翻訳する拡張です。

- ツールバーや右クリックメニューからページを翻訳
- 原文への切り替え
- サイトごとの自動翻訳設定
- キーボードショートカットで翻訳を切り替え
- 翻訳を禁止するページ側の指定にも対応
- ページの要素構造を保ちながらテキストを翻訳

Chrome 138以降のデスクトップ版が対象です。利用できる言語や端末はChrome内蔵Translator APIの対応状況に依存します。初回は翻訳モデルのダウンロードが必要になる場合があります。
画像内の文字、Canvas、PDFビューアー、コードや入力欄などは翻訳対象外です。

## 単一用途

閲覧中のWebページのテキストを日本語に翻訳し、原文への切り替えとサイト単位の自動翻訳を提供します。

## 権限を使用する理由

- `contextMenus`: 右クリックメニューに翻訳・原文復元・自動翻訳の操作を表示します。
- `storage`: 自動翻訳を有効にしたサイトのオリジンを端末内に保存します。
- `tabs`: 現在のタブやURLを確認し、サイト別の設定・バッジ表示・翻訳指示に使用します。
- `<all_urls>`: ユーザーが翻訳するWebページとフレーム内で、テキストの読み取りと置き換えを行います。

## データの扱いを確認する際のメモ

現在のソースでは、翻訳処理にChrome内蔵Translator APIを使用し、開発者のサーバーへページ本文を送信する処理やアクセス解析はありません。
ページ本文は翻訳処理で読み取るため、ストアのプライバシー申告では「データを扱わない」と一律に回答せず、各設問の定義に沿って申告してください。
